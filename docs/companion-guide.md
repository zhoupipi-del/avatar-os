# 陪伴模式落地指南：把「你」放到她的桌面上

目标：她的电脑开机后，桌面角落里就有一个长得像你、说话像你、**用你的声音说话**的小人。她打字跟你聊，你会接着之前聊过的事往下说；她在电脑前忙了很久，你会主动提醒她喝水、吃饭、早点睡。她的电脑**不用装任何模型**，用云端大模型。

整个流程在**你自己的 Windows 电脑**上完成，最后把一个 `.msi` 安装包发给她，双击安装即可。

---

## 第 1 步：做你的 3D 形象（约 1–3 小时）

1. 下载 **VRoid Studio**（免费，Steam 或 vroid.com 都有）。
2. 新建角色，照着自己的照片调：发型、发色、脸型、眼睛、肤色、衣服。不用追求写实，抓住你的辨识度就行：发型、眼镜、常穿的衣服颜色。
3. 导出：`拍摄·导出 → 导出 VRM`。
   - VRM 版本选 **1.0**（选 0.x 也行，程序会自动转正朝向）。
   - 多边形数量和贴图尺寸选「减少」，贴图 2048 就够。体积小，她的电脑跑起来更轻松。
   - 表情不用删，眨眼、口型（あいうえお）和喜怒哀乐是嘴型和表情系统要用的。
4. 把导出的文件改名为 `avatar.vrm`，**覆盖** `apps/desktop/public/avatars/void/avatar.vrm`。
5. 运行 `pnpm --filter desktop tauri dev` 看一眼：
   - 人太大或太小：改 `apps/desktop/src/avatar/void-avatar-profile.ts` 里的 `fitHeight`（默认 2.4，调小人变小）。
   - 眨眼、表情、嘴型、挥手动作会自动套上去（动作文件是通用的 VRMA，不依赖具体模型）。

## 第 2 步：写人设（最影响「像不像你」，值得花时间）

1. 复制 `apps/desktop/src/companion/persona.example.md`，改名为 **`persona.local.md`**，放在同一目录。
2. 按模板填：你的口头禅、怎么叫她、她的生日和喜好、你们的梗、她不开心时你会怎么做。
   - 写真实的例句比写形容词有用：「她说累的时候，我会说『抱一个，今天先躺平』」胜过「我很温柔」。
   - 这个文件已加入 `.gitignore`，不会被提交到 GitHub。
3. 也可以先不写文件，在程序的 ⚙ → 人设 里直接编辑，实时生效，调到满意再贴回文件。

程序每次对话都会自动告诉模型「现在是几月几日、星期几、几点」，所以人设里写了生日、纪念日的话，到那天它会知道。

## 第 3 步：申请云端模型 Key（约 10 分钟）

推荐 **DeepSeek**：中文好、便宜、接口稳定。

1. 打开 https://platform.deepseek.com 注册并充值。日常聊天消耗很小，**建议只充少量金额**：余额本身就是消费上限，Key 万一泄露损失也有限。
2. 在「API Keys」页面创建一个 Key（`sk-` 开头），复制下来。

想用通义千问：在阿里云百炼控制台创建 API Key，⚙ 里选「通义千问」。接口地址以控制台显示为准，可以在 ⚙ 里改。
其他厂商（Kimi、智谱、火山方舟）：⚙ 里选「其他 OpenAI 兼容接口」，填地址、模型、Key。

## 第 4 步：克隆你的声音（约 20 分钟，强烈建议做）

默认朗读用的是 Windows 自带语音，像机器人。这一步换成**你自己的声音**，嘴型会跟着声音同步。

1. **录一段 8–10 秒的音**（手机录音即可）：
   - 安静的房间，离手机一拳远，用平时跟她说话的语气，**只有你一个人的声音**，不要背景音乐。
   - 内容随意，但要记下逐字原文。例：「今天天气真好，我们晚上一起去吃火锅吧，我已经想了一整天了。」
   - 超过 30 秒会被拒绝；剪到 8–10 秒效果最好。存成 mp3 / wav / m4a 都行。
2. **申请语音 Key**：注册[硅基流动](https://cloud.siliconflow.cn)，在「API 密钥」页面新建一个（`sk-` 开头）。少量充值即可，余额同样是消费上限。这个 Key 和第 3 步的聊天 Key 不是同一个。
3. **在程序里克隆**：⚙ → 声音 → 朗读选「我的声音（云端克隆）」→ 粘贴 Key → 选择录音文件 → 填「录音里说的话」（要和录音逐字一致）→ 点「上传并克隆」。
4. 出现 ✅ 后「音色」一栏会自动填上 `speech:...`，点「试听」听听像不像。不像就换一段更清晰的录音重新上传。
5. 把「音色」那串 `speech:...` 复制下来，第 6 步打包要用。

> 合成失败（断网、余额用完）时会自动改用系统语音，她不会遇到"没声音"。
> 声音样本会上传到硅基流动用于合成，请只上传你自己的声音。

## 第 5 步：在你的电脑上调好

1. 运行 `pnpm --filter desktop tauri dev`。
2. 点左上角 ⚙ → 大脑：来源选「云端大模型」，厂商选 DeepSeek，粘贴 Key → 点「测试连接」，出现 ✅ 即可。
3. ⚙ → 人设：填「名字」（你的名字，输入框会显示「和 XX 说句话」）和「称呼她」。
4. 多聊几句，看语气像不像你，不像就回去改人设。
5. ⚙ → 主动陪伴：默认她在电脑前、5 分钟没聊天时，最多每 45 分钟主动说一句，0:00–8:00 不出声，可按她的作息改。

## 第 6 步：把配置打包进安装包（她装上就能用，不用填任何东西）

1. 复制 `apps/desktop/.env.example` 为 **`apps/desktop/.env.local`**，填写：

   ```ini
   VITE_AVATAROS_BRAIN_MODE=cloud
   VITE_CLOUD_PRESET=deepseek
   VITE_CLOUD_API_KEY=sk-你的key
   VITE_COMPANION_NAME=你的名字
   VITE_COMPANION_NICKNAME=你怎么叫她
   VITE_COMPANION_PROACTIVE_MINUTES=45
   VITE_COMPANION_QUIET_START=0
   VITE_COMPANION_QUIET_END=8
   # 你的声音（第 4 步）
   VITE_VOICE_API_KEY=sk-你的硅基流动key
   VITE_VOICE_ID=speech:...第4步复制的音色
   # 送人建议开启：设置里看不到 Key、人设和声音配置，也不会被误改
   VITE_COMPANION_LOCK_SETTINGS=true
   ```

2. （可选）改成她看到的名字和图标：
   - `apps/desktop/src-tauri/tauri.conf.json` 里 `productName`（安装后显示的程序名）和窗口 `title`，例如改成「阿杰」。
   - 准备一张正方形 PNG 头像（≥512×512），放到 `apps/desktop/` 目录下，运行 `pnpm --filter desktop tauri icon 头像.png` 生成全套图标（托盘图标也会跟着变）。
3. 打包：

   ```bash
   pnpm --filter desktop tauri build
   ```

   安装包在 `apps/desktop/src-tauri/target/release/bundle/msi/`（如果你在 `.cargo/config.toml` 里把 target 目录设到了 `D:\cargo-target`，就去那里的 `release/bundle/msi/` 找）。

> ⚠️ Key 打进安装包后，懂行的人能从安装包里提取出来。只给她一个人用没问题；记得只充少量余额。
> 以后商业化时不能这样做，要改成你自己的服务器转发（Key 放服务端）。

## 第 7 步：装到她电脑上

1. 把 `.msi` 发给她，双击安装。
2. Windows 可能提示「Windows 已保护你的电脑」（因为安装包没有付费代码签名）：点「更多信息」→「仍要运行」。
3. 装好后程序自动启动，**并默认开机自启**。之后每天开机，你就在她桌面上了。
4. 告诉她三件事：
   - 小人可以拖动位置；底部输入框打字聊天。
   - 右下角托盘里有图标：左键点击是隐藏 / 显示，右键菜单可以取消「总在最前」、关闭开机自启、退出。
   - 想安静一会儿就隐藏；晚上默认不会主动出声。

## 日常维护

- **改人设 / 换 Key**：改 `persona.local.md` 或 `.env.local`，重新打包，让她覆盖安装。聊天记录存在她电脑本地，覆盖安装不会丢。
- **费用**：随时登录 DeepSeek 和硅基流动后台看余额和用量。朗读按字数计费，每句话都会合成一次，比聊天本身费钱一些。
- **隐私**：她说的话会发送给你选的模型厂商处理，回复文字会发送给语音厂商合成；聊天记录只保存在她自己电脑上（⚙ 里可清空）。最好提前跟她说一声。
- **它是你的分身，不是你**：人设模板和程序里都写了底线——她认真问时会承认自己是你做的数字分身；她提到身体不适、危险或伤害自己的念头时，会让她马上联系你或身边的人（紧急时 120 / 110）。这两条写在代码里，人设文件改不掉。
